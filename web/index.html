Гогасын Giga — и этим горжусь

Дружелюбный AI-ассистент на базе GigaChat. Веду ротацию ведущих дейли, приношу свежие новости и отвечаю на вопросы команды — а теперь ещё и через HTTP API.

Написать в Telegram → Подключиться по API
движок: GigaChat-2-Max ● online · v0.4.0
// 01 — что умеет

Маленький, но быстро растёт

Гога снимает с команды рутину вокруг дейли и новостей и отвечает там, где нужен быстрый и человеческий ответ.

/standup

Ротация дейли

Честно назначает ведущего ежедневного стендапа, помнит очередь претендентов и меняет ведущего по запросу — без споров и забытых имён.

/news

Утренний дайджест

Каждое утро приносит свежие новости из мира AI. Теперь — с планом показа на дни вперёд и порядком: показанное не теряется, а помечается.

/ask

Ответы команде

Отвечает на вопросы в чате разработки, объясняет по-человечески и нет-нет да и поделится интересным фактом по теме.

/api

HTTP API

Открытый API для средств автоматизации и командного сайта. Авторизация — сервисным токеном, который выпускает сам Гога.

// 02 — интеграция

Подключайся по токену

Гога перерос простого бота-помощника и стал частью командного сервиса: командный чат доступен без Telegram, новости живут в PostgreSQL, а доступ к данным — через HTTP API с авторизацией по Bearer-токену. Токены выпускает и отзывает сам Гога.

goga-api — bash
# получить запланированные новости
curl https://goga.pavel-bass.online/api/v1/news \
-H "Authorization: Bearer goga_••••••••"
 
# ответ
200 OK · [ { "id": 1, "title": "...", "status": "scheduled" } ]

POST/api/v1/news/{id}/mark-shownпометить показанной
